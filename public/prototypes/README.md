# Stripe Fundraisers prototypes

Clickable concept prototypes for the business and organization experiences. They are static files with fictional data and no backend. They don't call the app's APIs or Stripe.

Run `npm run dev`, then open:

- Business: http://localhost:3000/prototypes/business.html
- Organization: http://localhost:3000/prototypes/org.html

Open both in the same browser. They share demo data through `localStorage`, so a change on one side appears on the other. Use **Reset demo** to start over.

Demo path: in the organization view, select **New fundraiser**, **Fill with example** and **Publish fundraiser**, then request a partnership with Boneyard Coffee. In the business view, open **Requests**, accept it and activate the partnership. Select **Simulate a day of sales** until the start date to see donations move.

The pictures are drawn placeholders. The public page imitates stripe.com for concept review and must keep its "Concept mockup" labels.
